# Contributing to Maestro

Thanks for helping improve Maestro.

## What to contribute

- Clearer phase templates in `phases.md`
- Better examples in `examples.md`
- Install docs and README presentation
- Bug fixes when phases are skipped or mis-ordered

## What belongs where

| File | Purpose |
|------|---------|
| `SKILL.md` | Orchestration, phase table, synthesis template |
| `phases.md` | Full methodology per phase — add depth here |
| `README.md` | GitHub presentation only |
| `examples.md` | End-to-end sample audits |
| `CHANGELOG.md` | Release notes |

## Pull request checklist

- [ ] Phase order in `SKILL.md` matches `phases.md` section order
- [ ] Master phase table updated if phases change
- [ ] `examples.md` reflects new behavior
- [ ] README table stays in sync with `SKILL.md`

## Code of conduct

Be constructive. Maestro is a discipline tool—clarity over cleverness.
